# Contributing to AAWF Skill

Thank you for improving AAWF.

## Before opening a pull request

- Keep execution inside the current host; do not add provider routing, account access, automatic model switching, or hidden-reasoning claims.
- Preserve intent, model-availability honesty, and transparent token estimates.
- Add or update benchmark cases when behavior changes.
- Run the local validation commands from the README.

## Pull requests

Describe the user-visible behavior change, the affected benchmark cases, and validation evidence. Keep changes narrowly scoped and do not include credentials, private prompts, or provider keys.

By contributing, you agree that your contributions are licensed under Apache-2.0.
